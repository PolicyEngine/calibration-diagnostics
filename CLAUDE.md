# Claude Code guidance

- When investigating a discrepant Microcosm calibration target, follow [the shared investigation workflow](docs/ai/workflows/investigate-microcosm-target.md) and its linked role-specific reviews.
- Before starting the application for Cross-dataset work, configure exactly one DIR or URL artifact location for each country you will use, as described in [the Cross-dataset application configuration](docs/cross-dataset-api.md#configure-the-application).
- Adding a Microcosm country is one entry in `packages/calibration-tree/src/countries.ts` in PolicyEngine/microcosm-collector, released as a new `@policyengine/calibration-tree` npm version, then a pull request here raising `frontend/package.json`'s pinned version; pages are gated by the registration's capabilities and the release artifact's `country` block, never by country code (see [the spec-driven countries note](docs/spec-driven-countries.md)).
- The calibration tree package (`@policyengine/calibration-tree`: the tree builder, its types and readers, the Blob I/O and the publisher) has its only source in PolicyEngine/microcosm-collector. Change it there and raise its version; this repository installs a published version from npm and keeps no copy.
